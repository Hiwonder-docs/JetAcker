# 6. Multi-robot Formation Manual

## 6.1 Muti-robot Communication Configuration

**If you need to control several JetAcker cars simultaneously, you need to connect the robots to the same network. The instruction of multi-robot communication configuration is given below.**

### 6.1.1 Definition of the Master and Slave

**Master**: receive the commands sent by the user and perform corresponding action. Then send the obtained command to the slave. And there is only one master device.

**Slave**: obtain commands from the master, and perform the corresponding action. And you can set one slave, or multiple slaves.

### 6.1.2 Preparations

- 2 or above JetAcker cars are required

- Prepare your own wireless router (optional). And wireless router of 5GHz is recommended. (If the router's performance is poor, group control may be choppy, actions may not be synchronized, and there may be delays.)

### 6.1.3 Network Connection Configuration

1.  Prepare a router and enable its WIFI function, and then connect all the robots to the same network.

> [!NOTE]
>
> The robot is set as AP direct connection mode by default. For more detailed information, please refer to "**[1.Getting Ready](https://wiki.hiwonder.com/projects/JetAcker/en/jetacker-jetson-nano/docs/1.Getting_Ready.html)**". If there are more than two robots, it’s not recommended to use the hotspot generated by the robot as it will result in lag and effect the experience. To control more robots, you must connect to a wireless router, preferably one with the 5GHz frequency band and high performance.

2.  Connect all the robots to the prepared WiFi.

##  6.2 Group Control

In group control, you can use one wireless handle to control multiple JetRover robots to perform actions simultaneously.

### 6.2.1 Preparations

1)  Prepare two and above JetAcker robots

2)  Install the virtual machine

3)  Configure communication for the both master and slave.

4)  Plug the USB handle receiver into the master,while the slave does not require a receiver. All slaves should unplug the handle receiver.
